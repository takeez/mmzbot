# 电脑状态上报协议

`pc_status` 扩展通过心跳接收电脑状态：电脑上的程序定时向机魂小悦发送 JSON。机魂小悦不会主动连接电脑。

## 请求方向

```
电脑（任意语言） --POST /api--> 手机上的机魂小悦
```

- 地址：`http://<手机IP>:17383/api`
- 方法：`POST`，`Content-Type: application/json`
- 鉴权：`Authorization: Bearer <config.json 里 bot.token 的值>`

## 正文

```json
{
  "action": "status.push",
  "ok": true,
  "日期": "2026-10-31",
  "专注": "3 小时 20 分",
  "摸鱼": "41 分 58 秒",
  "摸鱼来源": "Arknights 41 分 58 秒",
  "现在": "在写代码",
  "电脑名": "DESKTOP-EXAMPLE",
  "上报时段": "工作日 09:00-18:00",
  "时段": {
    "工作日": [1, 2, 3, 4, 5],
    "时段": ["09:00-12:00", "13:30-18:00"],
    "日期切换点": "04:00"
  },
  "UTC偏移": 8
}
```

字段说明：

| 键 | 必填 | 说明 |
|---|---|---|
| `action` | 是 | 固定 `"status.push"` |
| `ok` | 是 | 这份数据是否有效；`false` 表示本次状态不可用 |
| `日期` | 是 | 上报电脑的当前日期（`YYYY-MM-DD`）；跨时区按 `UTC偏移` 计算 |
| `专注` / `摸鱼` | 是 | 可读文本，原样传给模型，不做单位换算 |
| `摸鱼来源` | 否 | 无值时可省略该字段 |
| `现在` | 否 | 当前活动的简短描述；无值时可省略 |
| `电脑名` | 是 | 多台电脑时用来区分 |
| `上报时段` | 否 | 可读文本，仅用于日志和面板展示 |
| `时段` | 是 | 机器可读的工作时间；`日期切换点` 默认值为 `04:00` |
| `UTC偏移` | 是 | 电脑所在时区（小时，可为负） |

## 上报频率

- 每 **30 分钟**上报一次，仅在**工作日和工作时段**内发送；其他时段停止上报。
- 机魂小悦不校验上报频率；数据有效期依据 `日期` 字段判断，而不是依据距上次上报的时间。

## 状态读取规则

1. 调用 `pc_status` 时，先读取缓存中的最新心跳：
   - `日期` 与电脑当前日期一致：使用该数据，并附加其更新时间。
   - 日期不一致：按“电脑未开机”或“不在上报时段”处理。
2. 缓存中没有记录：说明尚未收到心跳。

## 心跳缺失时

不影响其他功能。`pc_status` 现在是一个**示例扩展包**（默认不装）：
`python phone-bot-v2.py --install-capability examples/packages/pc-status-1.0.0.zip`
安装后，模型还需读取一次技能说明才会解锁该工具。只有在**最近收到过心跳**时，工具才会出现在模型的工具目录中；没有心跳时，模型无法调用该工具。

## 安全

- 接口仅接受本机或局域网来源；公网请求默认返回 `403`。
- token 校验失败时返回 `403` 并计入失败次数；5 分钟内失败 10 次后返回 `429`。
- 接口只接收状态上报，不开放配置修改、重启或清除记忆等操作。
