# 扩展开发模板

此目录是供复制的最小扩展包模板，不会被加载器当作扩展包（目录名以 `_` 开头）。

1. 将 `_template/` 复制为 `capabilities/<包名>/`。包名只能包含小写字母、数字、连字符和下划线。
2. 修改 `SKILL.md` 中的 `name`，使其与目录名完全一致；`description` 应用一句不超过 60 字的话说明能力。
3. 如需工具，修改 `tool.py` 中的 `NAME`、`DESC`、`PARAMS` 和 `run`。若扩展只提供说明，可删除 `tool.py`。
4. 保存后无需重启；下一轮消息会刷新技能目录。

完整格式、六项校验和安装包说明见[扩展包格式规范](../../docs/capability-format.md)。
