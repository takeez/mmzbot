# 机魂小悦（MMZBOT）

**一个面向 QQ 场景、能够持续推进任务的 LLM Agent。**

面对复杂目标，会自主规划执行步骤，在推理过程中协同调用工具、分析结果并动态调整计划；需要等待时，可以安排延迟任务，并在未来唤醒后继续处理。由此，任务能够从一次对话出发，跨越多轮工具交互与时间间隔，形成从规划、执行到续办的完整闭环。QQ 是自然的交互入口，背后是一套**面向复杂任务的 Agent 执行能力**。

机魂小悦面向希望在 QQ 群聊和私聊中使用可扩展 Agent 的个人与小型社群。她通过 QQ 与用户交互，消息通道依赖 [NapCat](https://github.com/NapNeko/NapCat)，模型能力依赖你配置的兼容模型服务。

## 主要特点

### Agent 循环与稳定上下文

一条消息会进入“思考 → 调用工具 → 继续思考”的循环；工具轮次上限可以配置。工具由模型根据上下文决定是否调用，而不是仅靠匹配“提醒”“天气”等关键词来分发命令。

请求按稳定结构组织：人格、可选的技能目录、对话历史与场次信息，最后是用户当前发来的原话。技能目录独立维护，技能内容变化时替换目录，而不是不断追加；这有助于保持请求前缀稳定。

### 按需解锁扩展能力：知识锁

扩展包不会把所有工具说明和参数常驻塞进模型上下文。平时只提供已安装技能的名称与简述；模型判断需要某项能力时，再读取对应的 `SKILL.md`，该扩展的工具说明才会加入后续请求。

因此，安装很多扩展不会让所有扩展的工具 schema 一直占据上下文。已解锁的工具追加在现有工具之后，不重排已有工具；同时最多激活 6 个扩展包，超出时会移除最久未使用的包。

### 为 QQ 群聊和私聊分别设计

- **群聊**：默认名称为“机魂小悦”；名称和可选唤醒词出现在消息开头时会唤醒回复。另支持话题触发词、被 @ 必答、引用回复和按条件接话；有发言频率控制、群内单条长度限制，不会无节制刷屏。
- **私聊**：使用独立记忆和长度设置，适合连续对话。
- **多人记忆**：按用户和群聊区分记忆，称呼可参考群名片或好友备注；群里的私事不会被随意带到其他会话。
- **向量语义记忆**：使用 BGE-small-zh-v1.5 int8 将记忆编码为 512 维向量并按语义检索，是完整运行所必需的组件。模型采用 MIT 许可；实测内存约 78 MB，单线程每句约 37–41 ms，arm64 与 x86 输出逐位一致。模型从 [GitHub Release](https://github.com/takeez/miao-models/releases/tag/model-bge-small-zh-v1.5) 获取，不放入 Git 仓库，由 `model_quantized.onnx`（168 KB）、`model_quantized.onnx_data`（23.8 MB）和 `tokenizer.json` 三个文件组成。
- **多模态消息**：图片可作为推理材料；文件消息及引用中的文件可识别，并可按需下载供工具或扩展处理；表情和引用消息内容也能进入对话上下文。
- **工具**：内置 13 项工具能力，涵盖时间、计划、唤醒、记忆、用户信息、历史、天气、网页搜索与阅读、发言和技能读取等。是否调用由模型结合场景判断。

### 可安装的扩展包

扩展包采用 `capabilities/<名称>/` 目录结构，通常包含 `SKILL.md` 和 `tool.py`，也可以带 `config.json`。安装时会校验包结构、入口、工具函数、名称与参数等规则。

可通过命令行、面板上传 ZIP、网址安装，也可以使用仓库自带的 `pack-manager` 扩展管理其他扩展。模型读取技能说明后再决定是否使用扩展，不需要用户记住特定命令。

> **安全提示：** 请只安装可信来源的扩展，并在安装前检查代码和所需权限。

## 开始使用

开始群聊前，确保机器人 QQ 已加入目标群，并在面板中启用了该群。群聊里 @机魂小悦，或在消息开头使用“机魂小悦”及已配置的唤醒词，即可触发回复。引用一条带图片的消息，可以让机魂小悦识别图片内容。

也可以直接用自然语言管理称呼和记忆：

- “以后叫我小林”——记录你希望她使用的称呼。
- “记住我喜欢喝美式”——将这条信息写入记忆库。

## 设计参考

运行时循环、工具调用协议和请求组织方式参考了 [DeepSeek Harness（DSH）](https://www.deepseek.com/en/harness/)；Agent 的产品形态和工具组织参考了 [pi agent（pi-mono）](https://github.com/badlogic/pi-mono)。其余部分围绕 QQ 场景构建，包括群聊判断、知识锁、扩展包和管理面板。
